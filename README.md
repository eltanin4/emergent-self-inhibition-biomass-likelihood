# Emergent Self-Inhibition Governs the Landscape of Stable States in Complex Ecosystems

This repository contains the code and data used in the paper  
**“Emergent self inhibition governs the landscape of stable states in complex ecosystems.”**

Python version used: **3.11.5**

## Contents

- **main.ipynb**  
  This notebook contains all the plots used in the main paper.  
  At the end of the notebook, there is a short explanation of how to find all the stable states
  and how to compute the basin size for any given symmetric matrix.

- **likelihood_data/**  
  This folder contains all the data used for the probability and likelihood plots.

- **multistability.py**  
  This file contains the functions used to compute the stable states and their likelihoods.
